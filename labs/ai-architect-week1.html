Week 1 · Lab

Build the bigram predictor

You've seen the theory. Now you're going to write the math from scratch — no libraries, no magic, just Python dictionaries and a little probability.

By the end of this lab, your program will read a list of skateboarding tricks and predict what trick is most likely to come next. This is the exact same logic powering every large language model on the planet.

The core idea A bigram model counts how often word B follows word A. Then it divides by the total count to turn those numbers into probabilities. That's it.

Your tasks:

  1. Loop through the trick list and build a counts dictionary that stores how often each trick follows each other trick.
  2. Convert those counts to probabilities by dividing each count by the total for that starter trick.
  3. Write a predict_next(trick) function that returns the most probable next trick.
  4. Stretch: add a generate_sequence(start, n) function that chains predictions together into a full trick line.
Hint The starter code already loads your dataset as a list of strings called tricks. Use zip(tricks, tricks[1:]) to get every consecutive pair in one loop.
Stretch challenge

Change the dataset to a list of your own words — your name, your pet's name, whatever you want. Does the model "feel" different? Why?
